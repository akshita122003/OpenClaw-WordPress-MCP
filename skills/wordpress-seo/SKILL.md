# WordPress SEO Blog Skill

## When to use

Use this skill when the user wants:

* a new blog post
* SEO optimization
* WordPress publishing
* Elementor blog content

## Workflow

1. Research the topic using web search.
2. Generate an SEO title.
3. Generate a meta description.
4. Create H1, H2, and H3 structure.
5. Suggest focus keywords.
6. Publish the post using the WordPress MCP server.
7. Return the published URL.

## Output format

* SEO Title
* Meta Description
* Focus Keyword
* Blog Content
* Published URL
